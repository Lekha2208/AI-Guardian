# AI Guardian – Water Safety Monitoring System

## 📌 Overview
AI Guardian is a Python + MySQL based system that monitors water quality using turbidity and pH sensors.  
It detects unsafe conditions, diverts sewage automatically, sends SMS alerts, and maintains transparent records.

## 🎯 Objectives
- Detect unsafe water using sensors
- Divert sewage when contamination is detected
- Send SMS alerts to community contacts
- Maintain transparent records in a database

## ⚙️ Architecture
Sensors → Python Tkinter → MySQL → SMS → Transparency Dashboard

## 🖥️ Tech Stack
- Python (Tkinter, Pandas, Matplotlib, MySQL Connector)
- MySQL
- VS Code
